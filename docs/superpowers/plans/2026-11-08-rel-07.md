# REL-07 条款例外与冲突实施计划

> **For agentic workers:** Use the executing-plans workflow. Mark each task after fresh acceptance evidence.

**目标**。同库登记条款级例外和冲突，记录适用范围，支持复核与人工裁决。

**依据**。[文档关联总体改造](../../design/文档关联总体改造.md#待定能力清单)。

## 实施取舍

- 每端使用已有原生分块 ID 和同一原生快照中已观察的文档版本作为锚点。后端从已核验快照确认分块归属，扩展库只保存锚点和人工填写的适用说明、裁决及回执。页面复用已授权的原生分块列表，展示选中条款与锁定版本。
- `exception_to` 方向为例外条款指向通用条款，适用条件必填。审批确认该关系后展示为已确认。
- `conflicts_with` 记录两条有冲突的条款和适用范围。审核通过后保持「待裁决」，知识库管理者填写裁决依据，审计保存经办人、版本和时间。保留撤销与历史核对。
- 核对两端当前有效性和已观察版本后才允许确认或裁决。换版后的旧记录仍可在管理列表查看。关系图仅投影当前已核对的关系，冲突未裁决时明确提示。Agent 工具扩展与跨库另列 REL-09。
