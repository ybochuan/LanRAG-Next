- [x] 增加扩展迁移 024，保存两端版本、族修订号、确认状态、发布时间与业务发布头。保留已有观察链和提案外键。
- [x] 在 `extensions/business/family_replacement.go` 复用业务回执、CAS 和审计事务。旧件从 active 转 superseded，与关键边、发布头和生命周期 Outbox 一并提交。
- [x] 用现有 Host 定时任务执行到期替代，复用发布门禁、原生快照读取和同库授权。瞬态故障保留预约以便重试，确定的版本或成员变化转待复核。
- [x] 在隔离 Core/Host 验证原生写入口、预约检索门卫、自动执行、血缘方向和重复回执。扩展全量测试、构建、静态检查与模块检查均退出 0。

新件在批准预约之前沿用原可见性。预约取消或明确失效后，先前的可见性恢复，旧件保持原状态。已应用的替代保留审计和血缘，不能通过撤销操作复活旧件。已有业务发布头时，后续替代须指向该发布成员及锁定版本。

后续 FAM-03 先交付只读盘点与显式确认入口，隔离库验证回填与分库切换。FAM-04 再接入工作台与建议验收，真实标注不足时单独记录校准缺口。

## 历史更替链

工作台以制度生效日期排序，另显示系统登记时间。后续草案的旧件尚未成为发布件时提示等待，锁定的族修订或版本变化时提示重新核验。

沿用现有登录态管理入口的 `family_replacements?state=history-preview` 预览从已执行发布件开始的连续到期草案。最多预览 16 段，须核对单一链路、日期递增、成员和来源。已失效、待复核或有冲突的记录保留待查。确认经 `family_replace_history` 提交指纹、草案顺序和族修订号。各段替代复用原有事实写入，全部边、状态、发布件、审计与投影一次提交。失败保留原有事实，重试返回同一回执。

隔离用五版链注入最后一段的写入故障，验证整链回滚；真实接口使用 `AGENTRAG_FAMILY_HISTORY_E2E=1` 验证预览、确认、时间轴与重试。正式副本保留已执行的 2014→2018 记录，可预览 2020-01-01、2024-01-01 和 2024-09-01 三段，实际执行需以正式确认的制度日期为准。
