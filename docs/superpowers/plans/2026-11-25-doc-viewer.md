# DOC-VIEWER 阅读引擎升级实施计划

**目标**　实测 Zrimo 是否改善 Windows LanRAG Lite 的中文 DOCX 和复杂表格阅读。达到格式准入条件后，再将合格格式接入现有阅读中心。

**设计依据**　用户提交的《LanRAG-Next 多格式文档阅读引擎升级专项 v1.0》、[阅读中心 v1.1](../../design/LanRAG-Next-文档阅读中心与关联研读系统-v1.1-最终方案-2026-11-24.md)及[现有验收记录](../../evidence/document-studio-source-mapping-2026-11-24.md)。起始版本为 `87642ade`（`batch6-3-g87642ade`），阅读中心实现为 `5311e503`。

**技术栈**　现有 Vue/TDesign 预览组件、`@zrimo/viewer@0.1.2`、Vite 独立构建、Edge 自动化和 Windows Lite WebView2。原型用合成 DOCX 及 LibreOffice 参考渲染，业务样本验收须使用获准的本地脱敏件。

**2026-11-25 选型决定**　用户确认 Zrimo 阅读体验更好。正式前端代码将普通 DOCX 设为 Zrimo 默认路径，可经运行配置恢复原生兼容渲染。此次裁决调整阅读中心 v1.1 的 DOCX 原生预览复用边界。安装版发布继续执行 DV-P3 验收。

- [x] 在 `examples/doc-viewer-poc/` 独立锁定候选包，并验证包安装、运行资产复制与已安装包的发布签名。
- [x] 生成中文制度和跨页表单两个起始样本，记录 SHA-256、字体、LibreOffice 参考页和 Zrimo 末尾标记。
- [x] 用原生 TDesign 图标尺寸修复既有样式门禁。已复现失败并通过定向、全量、类型和独立输出构建检查。
- [ ] 在 Windows Lite 用脱敏文件采集首屏、长任务、双窗峰值及多轮切换基线。冻结正式性能预算并核对许可证及第三方 notices。

## DV-P1a 隔离原型

**文件**　`examples/doc-viewer-poc/` 提供单独的 npm 包、构建入口、界面、合成样本脚本和 Edge 冒烟。构建、PDF 参考、截图、哈希清单及诊断输出写入 `tmp/doc-viewer-poc/`。

- [x] 原生窗直接挂载仓库的 `document-preview.vue`，启用阅读中心的 `sourceMode` 和 Blob 输入。Zrimo 接收同一文件字节，提供 `ui:false` 受管理视口和可切换的上游工具栏。原型运行于回环地址，资源自托管。
- [x] Edge 冒烟阻断非同源请求。验证正文画面、中文搜索、两个实例、关闭一侧、快速切换和运行资产 MIME。证据见 [首轮 DOCX 对照记录](../../evidence/doc-viewer-poc-2026-11-25.md)。
- [ ] 根据参考页和原生页检查真实脱敏表格首末行、行序、跨页表头、正文编号、字体替代和图片裁切。Edge 隔离结果、实际 Windows Lite WebView2、人工排版确认分别记账。DOCX 通过后扩展 XLSX、PPTX，按格式决定准入，PDF 证据路径继续使用现有组件。

## DV-P1b 阅读窗格试接

DOCX 原型、双窗和同源构建已通过，用户确定首批引擎。合格范围为阅读中心的普通 DOCX。真实环境权限结果是安装版发布条件。

- [x] `ReaderPane.vue` 保持 `readerApi.ts` 的原生授权读取及前后元数据核对。每窗 DOCX 读取与 SDK 输入上限 50 MiB，已知超限时停止请求，未知大小则有界接收响应。卸载取消读取并销毁当前 SDK 实例。
- [x] TDesign 宿主工具栏及六语接线。每窗焦点、缩放、搜索和全屏独立，下载继续走原生授权。固定历史无原件证据时只显示记录，权限拒绝与版本冲突直接停止。
- [ ] 用真实 Core/Host 检查未授权目标的**接口响应**、附件失效和 Host 断开。若服务端返回不应暴露的关系元数据，先确认修正范围再修改 Core/Host。
- [x] 隔离构建验证台账→原文→关联→双窗→返回、历史原文拒绝、403、两种超限场景、同一 Blob 回退和运行开关。通过 `npm run check-i18n`、`npm run type-check`、`npm test`、`npm run build`。

## DV-P2 至 DV-P4

- **DV-P2**　完善格式能力驱动的缩放、页码、搜索和位置恢复。解析内容仅接入已核实的有序产物。
- **DV-P3**　补齐 Windows Lite 真机、真实授权、双窗峰值及资源释放、证据降级、构建清单和整包回滚。DOCX 以这次选型为准，其余格式独立验收并决定是否切换。
- **DV-P4**　仅在已定位的关键缺陷无法用上游配置或公共 API 解决时，单独评估 Fork 或 PDF 衍生预览。
