# M6-b 单库血缘图首版

本批基于 `d1f7945` 开发。原生界面的“血缘图谱”入口位于 `/platform/lineage`。更新Extension Host、重新编译Core并发布前端构建后，可在当前登录会话中查看真实图数据。

## 页面操作

1. 在导航选择“血缘图谱”，切换到有查看权限的知识库。
2. “版本历史”展示supersedes、merged_into；“内容溯源”仅展示derived_from；“文档关联”展示supplements、amends、interprets、related_to。
3. 在左侧按当前图中的文档名称或节点编号搜索。点击列表或画布节点可查看节点编号、文档编号、观测序号、当前文档生命周期和登记时间。
4. 使用按钮或滚轮缩放，拖动画布空白处平移。“适应画布”恢复完整视图。
5. 节点详情中的“内容溯源”和“版本历史”按该节点展开。点击“返回全库视图”恢复当前库的节点窗口。

箭头保留存储方向，derived_from从派生节点指向来源。节点名称取自当前原生文档标题，生命周期取自文档当前状态。“当前观测版本”表示该文档最近登记的观察版本，不能据此判断制度已经正式发布。

## 范围和显示边界

- 当前仅查询当前知识库。跨库查询和M6的其余运维、评估界面另行推进。
- 图数据来自现有ext_lineage_node和ext_lineage_edge，附件Metadata不自动产生血缘边。没有登记的来源和生产者不会被补画。
- 单图最多256节点、512边，达到上限时页面明确提示。全库窗口按登记时间选择最新节点，左侧搜索仅作用于当前窗口。
- 根节点展开复用现有最多10层、256节点的有界遍历；循环数据不会无限递归。无法完整展开时返回错误，可退回全库视图。
- 图数据属于管理元数据。阅读权限沿用原生JWT与KBRead，图不提供正文或绕过下载许可的能力。标题接口暂不可用时显示编号并提示。
